# joni

Personal playground (Next.js App Router) deployed on Vercel.

## Dev

```bash
npm install
npm run dev
```

## Content

- `content/pages/*.md` — simple pages rendered as markdown
- `content/posts/*` — blog posts (Jekyll `_posts` migrated)
- `public/legacy/*` — old one-off HTML pages preserved as static files

## Notes

This repo used to be a Jekyll site. That legacy is now removed from the build.
